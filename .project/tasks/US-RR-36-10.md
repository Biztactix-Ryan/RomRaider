US-RR-12-4 already wrote part of these (fixtures/public/ssm/init.toml, read-addresses.toml, read-memory.toml, writes.toml, errors.toml; checked by crates/rr-testkit/tests/ssm_fixtures.rs). Remaining per id:
- LEG-SSM-07 `ssm-init-echo`: init exchange byte-exact with echo, TX 6, RX 6 + 62 buffer sizing; ECU and TCU.
- LEG-SSM-08 `ssm-a8-single-shot`: `PP = 00` cycle, buffer size `(N+6)+(3N+7)`, fan-out to de-duplicated queries.
- LEG-SSM-09 `ssm-a8-continuous`: `PP = 01` stream read frame by frame; a line break stops it; stale bytes drained.
- LEG-SSM-10 `ssm-silent-ecu`: echo then nothing: typed timeout, retry per LinkProfile.
- LEG-SSM-11 `ssm-corrupt-midstream` (new): one bad-checksum frame in continuous mode yields no value plus a link-health event, never the previous frame (MF-08).
- LEG-SSM-12 `ssm-partial-timeout`: half a reply then silence: error after the LinkProfile deadline on a VirtualClock (MF-27).
- LEG-SSM-13 `ssm-trailing-bytes` (new): extra bytes after a reply and before a request drained, no misframing.
- LEG-SSM-14 `ssm-no-echo`: interface without echo reported as a link-profile mismatch (UL-SSM-05).
- LEG-SSM-15 `ssm-a0-block`: the ssm_info 128-byte `A0` read; RamTune-style range splitting with a remainder.
- LEG-SSM-16 `ssm-writes` (write-gated): `B8` matching/mismatching ack, corrupt-checksum ack rejected (UL-SSM-04), reset `000060` <- `40`, `B0` with data check.
