Smallest real-code path to the SPRINT-RR-6 goal (no SSM codec yet; that is US-RR-47). A read-only capture command (rr-cli `capture ssm-init` or an rr-link example) that: opens the KKL cable via the Serial Link (37-6) at 4800 8N1 from the adapter profile (37-10); wraps it in TraceWriter (33-7); sends exactly the ECU init request bytes pinned in fixtures/public/ssm/init.toml (`80 10 F0 01 BF 40`, docs/legacy/ssm.md §3.2), with the echo stripped and verified (37-7); waits for the reply until a Clock deadline; and writes the transaction to a .rrtrace file.

Safety: it sends only the BF init request. The command has no write path and accepts no arbitrary bytes (it goes through the rr-write-marker / check-writes rules). The output defaults to ~/RomRaider-private/traces/, never to the repo. The trace marks the ECU ID as a scrub field (33-9), since a real ECU ID is ROM-identifying (D-017, SECURITY.md).

Done when: replaying a trace through ReplayLink in a test reproduces the exchange; on a pty harness (37-11) a canned init reply from fixtures/public/ssm/init.toml is captured and round-trips; usage is documented for Ryan to run against the Liberty. The HIL run itself is recorded under US-RR-37-5.
